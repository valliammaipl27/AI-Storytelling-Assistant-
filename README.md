# Storyloom — AI Storytelling Assistant

**Storyloom** is a storytelling and scriptwriting assistant that helps users turn simple ideas into structured story drafts.

## ✨ Features

- 📝 **Story Generation** — Create a story draft from a simple prompt.
- 🎭 **Genre Selection** — Choose a genre for your story.
- 👥 **Audience Selection** — Select the target audience.
- 🎬 **Storyboard Planner** — Organize the story into three scenes.
- ⚖️ **Compare Drafts** — Compare your original draft with the generated draft.
- 💾 **Save and Copy** — Save story drafts and storyboard text.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 Live Demo

[**Open Storyloom Website**](https://valliammaipl27.github.io/AI-Storytelling-Assistant-/)


## 📌 How to Use

1. Open the Storyloom website.
2. Enter a story idea.
3. Select a genre and audience.
4. Click **Generate Story**.
5. Explore the storyboard and compare-drafts sections.
6. Save or copy your draft.

## 📖 Project Note

This version uses a browser-based story builder with predefined templates. It does not currently use a live AI API.
